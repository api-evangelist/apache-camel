Apache Camel 4.21 has just been released. This release introduces a large set of new features and noticeable improvements that we will cover in this blog post. Camel Core Error Registry The Error Registry has been enhanced to capture rich exchange data snapshots at error time, following the same pattern as BacklogTracer.
