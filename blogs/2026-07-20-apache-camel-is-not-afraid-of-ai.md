The Apache Camel project pointed a frontier AI model at 19 years of integration code and said: find what we missed. It found 165 bugs for the upcoming 4.22 LTS release. Not cosmetic issues — concurrency races, silent data loss scenarios, security gaps, and edge cases buried deep in 350+ connectors.
