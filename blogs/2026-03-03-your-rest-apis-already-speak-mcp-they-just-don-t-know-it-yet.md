Four years ago, I started writing an API Gateway. Not because I wanted to build a product — but because we needed more from the tools we had. I was working inside a government institution running a complex hybrid environment — services spread across on-premises data centers and cloud, strict security and compliance requirements, and a growing number of APIs that all needed to be managed, secured, and observed.
